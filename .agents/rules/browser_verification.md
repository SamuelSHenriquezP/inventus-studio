# Reglas de Proyecto: Verificación Web

## Restricción de Verificación en el Navegador
- **NUNCA** ejecutar verificaciones automáticas en el navegador web ni abrir subagentes de navegador por iniciativa propia.
- La verificación con el navegador web **SOLO** se realizará cuando el usuario lo solicite de manera explícita y directa.
- Para verificar el proyecto, utilizar exclusivamente `npm run build`, linting o comandos de terminal.
